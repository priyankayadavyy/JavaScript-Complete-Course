# 02. JavaScript Setup and Environment

## Requirements

To start learning JavaScript, you need:

1. Visual Studio Code
2. Google Chrome or another modern browser
3. Node.js (LTS version)
4. Basic knowledge of HTML

## Step 1: Install VS Code

Download: https://code.visualstudio.com/

## Step 2: Install Node.js

Download: https://nodejs.org/

Install the LTS version.

## Step 3: Verify Installation

Open the VS Code terminal and run:

```bash
node -v
npm -v
```

Both commands should display installed versions.

## Step 4: Create Your First JavaScript File

Create a file named:

`hello.js`

Write:

```javascript
console.log("Welcome to JavaScript!");
```

## Step 5: Run JavaScript

Open the VS Code terminal and execute:

```bash
node hello.js
```

Output:

```text
Welcome to JavaScript!
```

## Alternative: Run JavaScript in Browser

1. Open Google Chrome.
2. Press F12.
3. Open the Console tab.
4. Type:

```javascript
console.log("Hello from Browser!");
```

## Practice Task

1. Install Node.js.
2. Create `hello.js`.
3. Print your name.
4. Print your favourite programming language.
5. Run the file using Node.js.
