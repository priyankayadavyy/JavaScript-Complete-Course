# 01. Introduction to JavaScript

## What is JavaScript?

JavaScript is a high-level, dynamically typed programming language used to make websites interactive and dynamic.

JavaScript is one of the core technologies of web development:

- HTML – Defines the structure of a webpage.
- CSS – Defines the design and styling.
- JavaScript – Adds functionality and interactivity.

## Why Learn JavaScript?

1. Used in frontend development.
2. Used in backend development with Node.js.
3. Used in mobile application development.
4. Used in web applications and APIs.
5. Essential for modern web development.

## Features of JavaScript

- Lightweight programming language.
- Dynamically typed.
- Event-driven.
- Supports asynchronous programming.
- Object-based and prototype-oriented.
- Runs in web browsers and outside browsers using runtimes like Node.js.

## Where is JavaScript Used?

- Frontend: React.js, Next.js, Angular.
- Backend: Node.js, Express.js.
- Mobile: React Native.
- Full Stack: MERN Stack.

## First JavaScript Program

```javascript
console.log("Hello World!");
```

### Output

```text
Hello World!
```

## How JavaScript Works

JavaScript code is executed by a JavaScript engine.

Examples:

- V8 – Used in Google Chrome and Node.js.
- SpiderMonkey – Used in Firefox.
- JavaScriptCore – Used in Safari.

JavaScript is an essential programming language for modern web development. It helps developers build interactive websites, web applications, backend services and more.
